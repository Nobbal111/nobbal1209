About Me

My learning journey

Weekly Learning Journal

A growing collection of weekly reflections, new skills, challenges, and ideas from my academic and creative journey. Each entry records what I have learned and how I hope to improve.

Week 01 / Workshop Reflection

My First Steps in Website Creation

During the first week's workshop, I learned how to create a website and began exploring how digital content can be organised and presented online.

One of the most interesting parts was learning how to build a website with different sections, images, navigation links, and written content. I also learned that creating a website involves both creativity and attention to detail.

At first, the process seemed unfamiliar, especially when working with HTML and CSS. However, experimenting with the layout and seeing the page take shape made the experience rewarding.

Overall, this workshop gave me a useful starting point for developing my digital skills. I hope to keep experimenting with design, improve my understanding of web creation, and make my website more personal over time.

Week 02 / Web scraping

Web Scraping and Data Collection

This week, I continued developing my personal website. I learned how to upload images to GitHub, organise image files, and modify the HTML and CSS code to improve the appearance of my website. Through this process, I became more familiar with how a website is structured and how small changes in the code can affect its design.

Another important part of this week was learning how to scrape data from the web and collect it for use in research projects. This introduced me to a new way of gathering information online. I began to understand how web data can be collected and potentially used to explore research questions, identify patterns, and support further analysis.

Reflecting on this week, I realised that creating a website and collecting online data both require patience, attention to detail, and practical problem-solving skills. These activities also helped me think more about how digital tools can support communication and academic research.
